# aleksishmanov.ru landing

Автономная статическая страница: весь интерфейс, стили, скрипты, favicon и аватар встроены в `index.html`.

Для локального просмотра:

```bash
python3 -m http.server 8080
```

Затем откройте `http://localhost:8080`. Страницу можно разместить на любом статическом хостинге без сборки.
