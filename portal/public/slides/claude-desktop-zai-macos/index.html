Шаг 1 из 6 · 10 минут

Установка Claude Code

  1. Откройте подробную инструкцию по QR-коду
  2. Выберите свою операционную систему
  3. Установите Node.js 18 или новее
  4. Установите Claude Codenpm install -g @anthropic-ai/claude-code
  5. Проверьте установкуclaude --version
Подробная инструкцияhttps://aleksishmanov.ru/slides/instructions/claude-code/

Шаг 2 из 6 · 5 минут

Регистрация в Z.ai

  1. Откройте z.ai и нажмите Sign up
  2. Введите доступную почту
  3. Подтвердите вход кодом из письма
  4. Откройте страницу Coding Planhttps://z.ai/subscribe
  5. Оставьте вкладку открытой для оплаты
Подробная инструкцияhttps://aleksishmanov.ru/slides/instructions/zai-registration/

Шаг 3 из 6 · 10 минут

Оплата через MTS Payments

Важно. Z.ai нет в каталоге МТС. Используем зарубежную предоплаченную карту. Она не работает там, где нужен 3-D Secure.
  1. Откройте MTS Paymentspayment.mts.ru/tools/foreign-card
  2. Введите почту для получения реквизитов
  3. Выберите номинал не ниже цены плана
  4. Проверьте итог и оплатите через СБП
  5. Введите реквизиты карты на z.ai/subscribe
Подробная инструкцияhttps://aleksishmanov.ru/slides/instructions/zai-payment-mts/

Шаг 4 из 6 · 5 минут

API-ключ GLM

  1. Откройте обзор Individual Coding Plan
  2. Найдите блок API Key
  3. Создайте отдельный ключ для практикума
  4. Скопируйте его сразу после создания
  5. Не отправляйте ключ в чат и не показывайте на проекторе
Подробная инструкцияhttps://aleksishmanov.ru/slides/instructions/glm-api-key/

Шаг 5 из 6 · 10 минут

Coding Tool Helper

  1. Откройте Terminal или PowerShell
  2. Запустите мастер Z.ainpx @z_ai/coding-helper
  3. Выберите Global Coding Plan
  4. Вставьте API-ключ и отметьте Claude Code
  5. Загрузите план и запустите проверкуnpx @z_ai/coding-helper doctor
Подробная инструкцияhttps://aleksishmanov.ru/slides/instructions/zai-helper/

Шаг 6 из 6 · 5 минут

Первый запуск на GLM

  1. Создайте чистую папкуmkdir glm-practice cd glm-practice
  2. Запустите Claude Codeclaude
  3. Подтвердите использование API key
  4. Разрешите доступ только к папке glm-practice
  5. Отправьте проверочный запрос
