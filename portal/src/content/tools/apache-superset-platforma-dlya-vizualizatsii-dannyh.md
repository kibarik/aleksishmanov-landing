Open Source BI-инструмент (Business Intelligence), который позволяет строить интерактивные дашборды без кода и подключать десятки источников данных

⚡ Когда использовать?
✅ Нужны аналитические отчёты без участия разработчиков
✅ Хочется быстро собрать витрину данных из SQL-БД
✅ Нужно централизовать метрики для команды продукта

👨‍💻 Задача
Наблюдать за продуктовыми метриками (GMV, конверии и тп)

- Без инструмента
1. Аналитик пишет SQL-запросы вручную
2. Экспортирует в Excel
3. Делает графики
4. Повторяет всё заново каждую неделю

- С инструментом
1. Подключаем PostgreSQL к Superset
2. Создаём дашборд с фильтрами и метриками
3. Настраиваем автообновление и общий доступ

**Аналоги:**
- Yandex Datalens - внутри Яндекс.Облаке нативно
- Redash - больше SQL синтаксиса
- Metabase - проще, для малого бизнеса
