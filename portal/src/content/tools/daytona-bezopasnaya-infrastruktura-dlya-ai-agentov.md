Платформа для запуска AI-генерированного кода в изолированных sandbox-средах за 90 миллисекунд. Полностью программируемое API для создания, управления файлами, Git-операций и выполнения команд.

⚡ Когда использовать?
✅ AI-агенты должны выполнять код безопасно без риска для основной инфраструктуры
✅ Нужна быстрая изоляция для параллельного тестирования разных решений
✅ Требуется программный контроль над средами разработки через API
✅ Важна совместимость с Docker и возможность масштабирования

👨‍💻 Задача
1. Запуск тулов MCP-Coder в изолированной среде
2. Хочу чтобы AI-агенты работали в 3-5 параллелей, но с общей кодовой базой и git

**Контейнеры (Kubernetes/Docker-compose )**
(Что происходит под капотом системы)
- Настраиваете Docker Compose с 5 изолированными контейнерами для каждого агента
- Конфигурируете volume mounting для доступа к Next.js кодовой базе
- Настраиваете сетевые политики и ограничения
- Прокидываете порты и мониторинг
- Скрипты и управление жизненным циклом
- Прикрутить какой-то инструмент управление транзакциями и тп

**С Daytona**
PS все что выше уже под капотом, сюда еще админка + SDK готовый
- Пишем скрипт отгрузки изменений (напр. по вебхуку брать обновления с git, запускать AI-агентов)
- Через Python/JS SDK настраиваем окружение (.env, volume, sandbox, отгружаем код)
- Выдаешь агенту Prompt + доступы к среде исполнения
- Из коробки есть крутая инфра для AI-агентов AgentToolbox (Git, Files, LSP-server, Code-Process, logs, MCP-сервера и другое)
- Видим Preview проекта по веб-ссылке на домене
- Видим все изменения в админке, также можем управлять ручками

**Как еще быстрее?**

Меньше времени на настройку, проще стартовать. Но нельзя настроить Self-hosted запуск
