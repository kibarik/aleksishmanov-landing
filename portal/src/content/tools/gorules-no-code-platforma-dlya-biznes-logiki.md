Позволяет описывать правила принятия решений в визуальном интерфейсе и встраивать их в любые приложения через API

**⚡ Когда использовать?**
✅ Автоматизация проверок и правил (например, кредитные, скидочные, антифрод)
✅ Быстрое обновление бизнес-логики без участия разработчиков
✅ A/B тестирование правил и условий
✅ Интерфейс отладки для непрограммистов

**👨‍💻 Задача**
Маркетплейс хочет менять тариф доставки по регионам

**Без инструмента**
1 PM → dev
2 Код + тесты
3 Деплой
4 Повтор при каждом правиле

**С инструментом**
1 Операционист редактирует Decision Table
2 Publish — API сразу считает новую цену
3 Версии хранятся внутри BRMS

**🛠 Comparison with similar tools:**
🔹 Drools → Java-монолит
🔹 Camunda DMN → BPM-фокус
🔹 DecisionRules → SaaS, нет OSS
