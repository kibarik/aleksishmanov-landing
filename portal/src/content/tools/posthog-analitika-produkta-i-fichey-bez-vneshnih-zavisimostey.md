Платформа “всё в одном” для **сбора, анализа и тестирования пользовательских данных**, которую можно развернуть **у себя на сервере**.

👨‍💻 Задача
Отследить, какие функции маркетплейса реально повышают конверсию продавцов — например, новая форма загрузки товара

С PostHog
- Отправка событий (клики, действия) прямо из фронтенда через SDK
- Встроенные фиче-флаги для тестирования новой загрузки товара
- Визуальные воронки и когортный анализ прямо в интерфейсе
- Всё хранится локально или в приватном облаке

**🛠 Похожие инструменты под свою специфику**

- Яндекс.Аналитика. Классика для веба
- **Mixpanel** — выбор продакт-менеджеров с бюджетом
- **Amplitude** — в крупных компаниях (банки, e-commerce)
- **PostHog / Matomo / Plausible / Swetrix** — у стартапов и корпораций с политикой приватности
- **Smartlook / Plerdy / Hotjar** — для визуализации поведения (тепловые карты, записи)
- **Metabase / Redash** — BI-дашборды на данных из PostgreSQL
