Kanban-трекер с открытым API, оптимизирован для быстрого кастомного фронтенда

⚡ Когда использовать?
✅ Нужен свой UI без разработки backend
✅ MVP продукта с задачами и ролями
✅ Внутренние инструменты для команд

👨‍💻 Задача
Добавить таск-трекер в свой проект, чтобы на основе AI аналитики руководители могли отслеживать статус исправления поставленных задач

**Без инструмента** (оч дорого и долго):
Писать с нуля свой код и раскатывать - очень дорого для гипотезы, много рисков.
• Реализовать Frontend
• Написать куча backend функций
• Написать коннектор backend+frontend
• реализовать frontend

**Коммерческий вариант** (цена от 5 до 10$ за каждого пользоватля)**:**
• у пользователей разные таск-менеджера (JIRA, Trello, Bitrix24, ClickUP, 1C, amoCRM-задачи) - не охватим большинство из них
• большинство Todo приложений собирают оплату за пользователей. У нас 1 руководитель и 15 подчиненных, если интегрируемся - то не окупимся по UNIT-экономике.

**Через Planka:**
step 1:
• для теста гипотезы полностью переиспользуем проект по API
• если гипотеза мертва - выкидываем
step 2:
• пишем свой frontend под стили
• подключаем прослойку между frontend, backend и planka
• выпускаем в Production

PS Пересмотрел кучу других инструментов, Planka оказалась единственной качественной, стабильной и рабочей. Из достойный, но платных альтернатив - https://plane.so/, но очень перегруженные
