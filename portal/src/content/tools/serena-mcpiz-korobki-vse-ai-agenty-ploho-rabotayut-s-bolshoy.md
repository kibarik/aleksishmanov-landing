Как использовать:
• добавить в ClaudeCode для исследования по коду
• помогает ориентироваться в микросервисах
• помогает ориентироваться мжеду репозиториями
• помогает исследовать кодовую базу
• позволяет сохранять контекст поиска для экономии токенов

GitHub: https://github.com/oraios/serena

Еще пару альтернатив, для работы с индексом кода под специфичные задачи рефакторинга:
• [Repomix](https://repomix.com/) - упаковка кодовой базы в единый AI-friendly файл. Удобно для документации
• [MCP-Codebase-Index](https://github.com/johnhuang316/code-index-mcp)- аходит транзитивные зависимости функций по коду. Мгновенный ответ на вопрос «что сломается если изменить X?»
• [Code-Graph-MCP](https://github.com/CodeGraphContext/CodeGraphContext)- для кодовых баз свыше 500K строк, формирует граф для AI-агента с быстрым переходом к нужному блоку.
