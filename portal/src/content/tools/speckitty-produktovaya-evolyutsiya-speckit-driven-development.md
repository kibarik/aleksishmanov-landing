Параллельно [VibeKanban](https://t.me/corporate_ai/47) развивается второе проект управления параллельными разработками. Ребята взяли базовый [Spec-Kit](https://github.com/github/spec-kit) и доработали в него удобные фичи для продуктовой разработки.

Если кто Speckit уже освоил, то Spec-kitty добавляет крутые фичи поверх базовой инфраструктуры:
- Review кода через AI-агента
- Kanban доски для параллельно
- углубленные режимы сборы контекста (Research, Documentation, Development)
- accept/deny и merge команда
- WEB UI с канбан доской
- дефолтное разделение main для планирования, gitworktree для разработки
