Open-source платформа для перемещения данных (ELT/ETL) между любыми источниками и хранилищами.
600+ готовых коннекторов, от баз данных до SaaS-сервисов. Конкурент коммерческого [Fivetran.com](http://Fivetran.com/)

**Задача:**
Без дорого дата-инженера научиться в AI-агента данные от бизнеса (CRM, БД, S3).

**Как использовать?**
• подключаешь источники
• настраиваешь загрузку данные
• сохраняешь в свое хранилище (warehouse)
• для AI-агента используешь актуальное хранилище

**Два режима работы:**
• Data Replication Engine — классический ELT для аналитики и DWH
• Agent Engine — real-time коннекторы для AI-агентов, которым нужны живые данные

**Альтернатива:**
https://meltano.com/ - больше про code-first, отсутствует CDC подключение. Больше для технарей
