Высокопроизводительный сервер для статических сайтов, API и проксирования, созданный как форк NGINX, но с современным подходом

⚡ Когда использовать?
✅ Нужна альтернатива NGINX с понятной конфигурацией
✅ Важно быстрое масштабирование и высокая производительность
✅ Требуется поддержка HTTP/3 и современный TLS out-of-the-box

PS Похоже как просто обновление Nginx с чуть более новыми функциями и производительностью
