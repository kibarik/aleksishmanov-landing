OpenSource аналог [deepwiki.com](http://deepwiki.com/)

Преобразует любой репозиторий (на GitHub / GitLab / Bitbucket) в удобную вики-документацию: анализирует структуру кода, строит диаграммы, генерирует описания и позволяет задавать вопросы “на естественном языке” к коду (RAG-подход)

⚡ Когда использовать?
✅ Когда нужно быстро “раcшарить” внутреннюю структуру большого/чужого кода (для команды, аудита, онбординга)
✅ Когда нет или устарела документация — и нужно её сгенерировать заново
✅ Когда хочется интерактивной вики + возможность задавать вопросы к коду без ручного чтения
✅ Нужен удобный MCP-сервер для поиска зависимостей проекта со старым Legacy
✅ Упростить онбординг сотрудника в экосистему

👨‍💻 Задача
PS Мне нужен контекст из большой экосистемы Legacy кода для SpecKit

На этапе планирования этапа разработки - SpecKit должен где-то брать доп. контекст о связанных зависимостях.

Без DeepWiki:
- ориентация на автотесты
- ориентация на git MCP
- знания из конституции или PRD

С DeepWiki:
- валидация кода с DeepWiki MCP
- доступ к любому количеству репозиториев
- всегда актуальный контекст по репозиториям
- AI сам себе собирает контекст
- AI ассистент в формате «как можно реализовать функционал/как реализован функционал»
