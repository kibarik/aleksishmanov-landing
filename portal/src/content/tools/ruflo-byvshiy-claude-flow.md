Платформа для оркестрации Claude Code агентов. Для от тех, кому мало одного агента и нужна настоящая рой-система прямо из терминала.

Как использую:
Ранее создал своего агента в Claude Setup с микроагентами которые работают через общий беклог. Решение ок, но есть много проблем с качеством следования инструкций и отсутствием параллельности разработки + сложность масштабирования под микро сервисы. И главная проблема - это разрозненная память и непрозрачный контроль между этапами. И нельзя сделать вложенность больше 1-го Claude агента.

Начал строить что-то свое на Temporal и других проектах и нашел эту тулу. Всем советую попробовать.

Что делает  RuFlo:
- управляет роем агентов
- использует ClaudeCode для спама агентов
- общая память
- общие MCP
- цикл самообучения
- настраиваемые агенты
- метрики потребления
