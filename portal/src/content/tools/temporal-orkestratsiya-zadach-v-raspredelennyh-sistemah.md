Платформа для надёжного исполнения бизнес-логики. Упрощает работу с асинхронными задачами, ретраями, дедлайнами и долгоживущими процессами без боли с очередями и состоянием.

**⚡ Когда использовать?**
✅ Надёжная обработка фоновых задач
✅ Интеграция API и микросервисов с контролем состояний
✅ Долгоживущие бизнес-процессы (например, бронирования, доставки)
✅ Упрощение работы devops-специалистов
✅ Повышение эффективности команды

**👨‍💻 Пример из практики**
Обработка заказа в e-commerce. Типовой бизнес-процесс:
оформляет заказ -> оплата -> упаковка -> доставка

- **без Temporal**
Разработка
1️⃣ Написать 4 сервиса
2️⃣ Настроить очереди (RabbitMQ)
3️⃣ Реализовать логику повторов, дедлайнов
4️⃣ Поднять state репозиторий в БД
5️⃣ Сделать мониторинг, алерты
6️⃣ Обрабатывать сбои вручную
Деплой
1️⃣ Поднять очереди
2️⃣ Настроить retry/timeout
3️⃣ Настроить логирование
4️⃣ Проверить, чтобы шаги не дублировались
🧠 Итого: ~10 действий, много glue-кода

- **с Temporal:**
Разработка:
1️⃣ 1 workflow, 3-4 активности
- Повторы, таймеры, статусы — "из коробки"
Ф Вся логика в одном месте
Деплой:
1️⃣ Поднять Temporal
2️⃣ Задеплоить сервис
3️⃣ Мониторинг — сразу в UI
🧠 Итого: ~4 действия, всё в одном месте. Разделение зон ответственности

**- корп. альтернатива**
Заявка в devops на выделение ресурса для настройки инфраструктуры. Проблема решается через трудочасы и тратится больше денег.
