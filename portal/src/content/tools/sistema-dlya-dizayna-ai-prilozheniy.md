https://www.pencil.dev/
Система для дизайна AI-приложений. В отличие от [bolt.new](http://bolt.new/) и прочих облачных решений запускается локально и использует Claude Code

**Как использую:**
В основном когда уже готов и отлажен весь Backend слой (FastAPI, Temporal, БД, AI-сервисы) создаю удобный интерфейс. В целом считаю что лучше разделять приложения: отдельно для планирования&аналитики (VibeKanban + Claude Code PM Setup), отдельно для разработки (Superset + Claude Code Everything Setup), отдельно для тестирования (), отдельно для дизайна (OpenPencil, PopMelt)

**Что он делает:**
• Создает интерфейс
• Работает на базе OpenSource моделей
• Рисует дизайн
