Ребята сделали Codex интерфейс для Claude Code агента. Для непрограммистов, которые не сидят 24/7 в терминале и VS Code

**Как использую:**
Вместо Codex, очень нравится их UI интерфейс и удобство работы с AI-агентами. Запускаю [Superset.sh](http://Superset.sh/) когда нужно отдебажить и через него отслеживаю всех своих агентов. VibeKanban использую для сложных проектов где у меня уже куча фичей и аналитики. Superset - для быстрого сбора прототипа за вечер.

**Что он делает:**
• Позволяет запускать множество CLI-агентов параллельно
• Удобный и минималистичный интерфейс с акцентом на AI-диалог, а не на код
• Мониторинг статусов агента
