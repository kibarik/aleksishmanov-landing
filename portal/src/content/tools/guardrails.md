Контроль и защита при работе с LLM
Python-фреймворк для безопасных и структурированных AI-ответов

⚡ Когда использовать?
✅ Нужно фильтровать токсичный или опасный контент
✅ Гарантировать корректный JSON/XML
✅ Предотвратить утечку данных через LLM

**👨‍💻 Какую проблему решает**
Безопасный доступ к ИИ без риска слива внутренних данных при подключении внешних LLM (Copilot, API, ассистенты)

- Без инструмента
Сотрудник подключает внешний LLM → сливает всё, что знает внутренняя модель (пароли, комментарии, код)

- С Guardrails
1. Прокси-защита для Input/Output
2. Обнаружение “prompt-хакинга”
3. Блокировка и логирование сомнительных запросов

🛠 Comparison with similar tools:
🔹 Rebuff → защита на уровне prompt
🔹 Outlines → строгий вывод по схеме
🔹 LMQL → контроль генерации
