Позволяет запускать код в изолированных контейнерах прямо из браузера

⚡ Когда использовать?
✅ Нужно встроить Python/Node окружение в продукт
✅ Нужна облачная песочница для кода
✅ Хотите дать пользователю возможность что-то “прогнать” без настройки среды

👨‍💻 Задача
Добавить в AI-агента возможность запускать исполняемый код и отправлять результат его работы. Очень полезно когда нужно работать с преобразованием данных, AI-агент сможет запустить исполняемый код в песочнице, отдать результат и закрыть сессию
