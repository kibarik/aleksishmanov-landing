AI-агент умный, но недисциплинированный — получает задачу и сразу пишет код, не уточняя требований, не планируя, не покрывая тестами.
Superpowers — это набор skills (markdown-файлы с правилами) для Claude Code, который встраивает дисциплину в сам процесс. Агент больше не стартует с кода: сначала задаёт уточняющие вопросы, оформляет спек, разбивает на задачи по 2–5 минут, запускает субагентов на каждую задачу с двухэтапным ревью — и только потом коммитит.

Что важно знать:
• Жёсткий TDD: сначала падающий тест, потом минимальный код для прохождения — никаких исключений
• Skills компонуются и расширяются — можно писать свои под стек команды
• Работает с Claude Code, Codex, OpenCode — методология переносимая
• 107k звёзд на GitHub за 5 месяцев, open-source, MIT

Как использовать:
Всегда генерирую код через /superpower.using-superpower и из коробки получаешь хорошего качества кодогенерацию с предварительным исследованием, спецификацией, планированием, разработкой, отладкой и самопроверкой.
