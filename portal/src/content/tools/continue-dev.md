Самопроверка для AI-кодогенерации, запускается по команде и проводит CodeReview по заданным стандартам. В локальной версии позволяет проверить коммиты перед запуском, в облачной версии проводить ревью коммитов в формате PASS/FAILED. Помогает отлавливать пустую кодогенерацию, чтобы не захламлять репозиторий бесполезными изменениями.

**Как использовать?**
• Проверять качество кодогенерации перед отправкой в прод
• Добавить в PR-ревью как комментатора, чтобы отлавливать плохие участки
