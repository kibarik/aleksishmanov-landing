Связывает LLM с вашими внутренними базами знаний: Wiki, PDF, SQL и др.

⚡ Когда использовать?
✅ Нужно быстро внедрить интеллектуальный поиск по Confluence, Notion, Google Docs
✅ Требуется RAG (поиск+генерация) поверх нестандартизированных данных
✅ Нужно кастомизировать пайплайн: фильтры, метрики, логика ранжирования

👨‍💻 Задача
Сделать AI-поисковик по внутренней Wiki компании

- Без инструмента
Ответы даёт ChatGPT "вслепую"
1. Скачивание всех страниц
2. Конвертация форматов
3. Индексация вручную
4. Связка с поиском — через код

- С инструментом
LlamaIndex сам выстраивает пайплайн
1. Подключение источников (Confluence, Notion)
2. Автоиндексация и обновления
3. Встроенный RAG по запросу
