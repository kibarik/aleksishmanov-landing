Open Source инструмент, который автоматизирует создание, обновление и удаление задач и страниц Atlassian (Jira, Confluence) через AI-агентов

**⚡ Когда использовать?**
✅ Массовое создание задач в Jira по шаблону
✅ Версионирование задач и документации через Git
✅ Генерация страниц Confluence из YAML
✅ Быстрая интеграция с AI-агентом

**👨‍💻 Пример из практики:**
Для себя ищу вариант как подключить моих AI-агентов к корп. системе, при этом не тратить много ресурсов на описание оберток и не нарушать корп. политику. MCP-сервер упрощает настройку и первый запуск.

**Без MCP**:
- Настроить JIRA API токен
- Написать скрипт или плагин для интеграции
- Обработать авторизацию и формат JSON вручную
- Учитывать структуру каждого проекта Jira
- Отправить запрос вручную или через AI-агента
- Обновлять и поддерживать код при каждом изменении
**С MCP:**
- Настроить MCP (один раз)
- Подключить Jira через конфиг
- AI-агент просто генерирует YAML
- MCP автоматически создаёт задачи, страницы, обновления
