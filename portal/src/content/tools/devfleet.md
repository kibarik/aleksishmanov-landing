Open-source платформа, которая запускает AI‑агентов на твоих задачах в GitHub. Можно использовать для PR, можно для Review, можно настроить для отладки. По-сути запускает Claude Code в облаке и помогает привязаться к Github Actions.

Что важно знать:
• Работает с Claude Code по твоему ключу
• Задачи выполняются асинхронно и параллельно — не надо ждать
• Можно развернуть на своём сервере, данные никуда не уходят

Docs: https://www.devfleet.ai/docs
