Ситуация
Дорабатываю интерфейс от Claude Design в уже рабочем проекте Claude Code — много мелких правок на действующем коде

Проблема:
Через 10 итераций Claude Code сильно уходит от исходного дизайн-концепта. Каждая микро-правка на реальном проекте — это агент, который хуже Claude Design держит UX

Решение
Подключить UX Core ([keepsimple.io](http://keepsimple.io/)) и Popmelt при отладке багов на действующем коде — первый даёт агенту логику поведения пользователя, второй держит визуальную консистентность и историю решений

В отличие от Claude Design, оба работают нативно поверх Claude Code с полным контекстом кода — отладка идёт быстрее, без пересборки контекста заново

[https://keepsimple.io](https://keepsimple.io/)
https://popmelt.com/
