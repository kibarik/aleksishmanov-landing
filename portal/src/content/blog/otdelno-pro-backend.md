Для меня это отдельная боль, тк 90% всех проектов для теста гипотез - это примитивные REST сервера которые подключаются между разными сервисами. Раньше на все использовать VPS-машины, потом перешел на Coolify, затем на Apps. Но все равно проблема остается та же - нужно ежемесячно держать и обслуживать сервер с какой-то регулярной стоимостью.

После исследований и экспериментов
Оказалось что 95% экспериментальных проектов хватает FaaS платформ (Functions As A Service). Когда вместо полноценного Web сервера используешь простые функции. А платформа берет на себя всю логику с их обслуживанием и управлением. Платформы которые исопльзую:

РФ:
• Yandex Cloud Functions   (основной)
• Advanced FunctionGraph от [Cloud.ru](http://Cloud.ru/)

Межнар:
• AWS Lambda
• Google Cloud Functions
• DigitalOcean Functions
