Сервисы о которых говорил:
- https://deepwiki.com/ / OpenDeepWiki - очень удобно собирает контекст между репозиториями по большому проекту
- [https://onyx.app](https://onyx.app/) - AI Confluence, просто очень прокаченная RAG читалка. Очень хорошо работает с классическим текстом, использовал в тех. поддержке и клиентском сервисе. У Яндекса аналог - это Я.Нейроэксперт. Еще удобный https://www.kapa.ai/ -  когда RAG-агенты нужны
- https://entire.io/ - Git версия для управления контекстом, чтобы в любой момент откатиться к чекпоинту или посмотреть "что было в прошлой сессии"
- [https://superset.sh](https://superset.sh/)  - просто очень удобная штука для запуска агентов в отладку, через нее генерирую. Затем уже когда все доделано - иду в VisualStudio додебажить плохой код. В своих проектах тут у меня сидят PM+аналитик, управляют VibeKanban доской (здесь работают DEV-агенты задачки исполняют)

Claude Code сетап агента аналитика:
- [https://docs.spec-kitty.ai](https://docs.spec-kitty.ai/). - вместо SpecKit использую. Просто качественно исследует задачу и делает верхнеуровневый план. Очень хорошо собирает контекст. Разделяет задачи на 5-10 WP задач, каждую WP разделяет на 15-20 TP подзадач простых, для каждой TP задачи прописывает чеклисты приемки. - https://search.brave.com/ - поисковик, встроенный в GLM/Claude Code ужасно плохо работает
- https://github.com/kibarik/Deb8flow/ - своя тулза, использую чтобы почелленджить документы, архитектуру, PRD и тп. Задает вопросы, потом кидаю их на агенты для доработок

Claude Code сетап агента разработчика:
- https://github.com/MrLesk/Backlog.md - беклог вместо VibeKanban, как внешняя память для управления беклогом
- https://github.com/obra/superpowers -  берет задачу с доски после Spec-Kitty и пишет на нее отдельный исследование, планирование, декомпозицию, отладку, ревью. Очень круто работает с длинным контекстом - просто musthave попробуй. Особенно режим TestDrivenDevelopment и отладки, потрясающе хорошо работает
- https://context7.com/ - перед стартом разработки узнает что и как делать
- https://continue.dev/ - подключен в Github репозиторий, проводит CodeReview (уязвимости, архитектура, говнокод), просто удобная версия Claude Code Review CLI. Можно в VisualStudioCode поставить локально для удобства
- https://github.com/thedotmack/claude-mem - память между сессиями Claude Code на одном проекте
- ClaudeCode insights - встроенная штука, но очень рекомендую ее после каждой кодогенерации использовать
- [https://entire.io](https://entire.io/) - чекпоинты в Git с полным AI контекстом, чтобы можно было откатиться если хрень сгенерировалась + удобная отладка
• https://github.com/anthropics/claude-plugins-official/blob/main/plugins/code-simplifier/agents/code-simplifier.md - упрощатель кода
