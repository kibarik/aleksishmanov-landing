Shotgun превращает любую папку проекта в единый текстовый payload, где структура и содержимое готовы для анализа и редактирования нейросетями. Этот формат отлично подходит для задач массовых изменений, рефакторинга, генерации документации и онбординга новых участников.

**Когда применять Shotgun?**
- Массовый рефакторинг или багфикс сразу по нескольким файлам: LLM видит весь контекст без потери связей между файлами.
- Подготовка к ревью или онбордингу: вся кодовая база доступна для быстрого ознакомления в чатах с ассистентом.
- Автоматическая генерация документации по всем публичным API символам проекта.
- Сценарии, где нужно “взорвать” пакет файлов в один текст — чтобы LLM увидел даже глубокие зависимости и мог дать большой дифф на всю базу.

**Как работает?**
- Выделяете папку, отмечаете файлы, которые не нужны (логи, сборки, временные).
- Получаете вывод со структурным деревом и блоками  <file path="...">...</file>  — легко парсится и не путает LLM.
- Копируете результат в ChatGPT, Gemini, Cursor или любой редактор с LLM-поддержкой.
- AI-ассистент возвращает diff (разницу), которую можно применить сразу в весь репозиторий одним патчем.
