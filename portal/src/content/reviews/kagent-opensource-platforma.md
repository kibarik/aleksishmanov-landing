**Когда применить**
Я вообще искал ответ 'как создать Enterprice-платформу без возни с devops и observability'. В формате закинул python код и получил полностью рабочую экосистему. С Prometheus, Graphana, Очередями, Kubernetes, Логами и средой для тестирования. Изучил многие решения: [AgentGateway](https://agentgateway.dev/), [Kortix Suna](https://github.com/kortix-ai/suna), [Temporal](https://temporal.io/), [Daytona](https://www.daytona.io/), [Onyx](https://onyx.app/), [OPEA](https://opea-project.github.io/latest/index.html)

**Целевая задача:**
Развернуть сложных/многокомпонентных AI-агентов/MCP-сервера за 1-2 клика в Kubernetes. И получить удобную экосистему для мониторинга и отладки

**Что под капотом:**
- kubernetes
- CLI запуска шаблонов агента
- дашборд отладки AI-агента
- дашборд отладки MCP-тулов
- [fastmcp](https://gofastmcp.com/getting-started/welcome)
- [agentgateway](https://agentgateway.dev/)
