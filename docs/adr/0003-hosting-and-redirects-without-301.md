# Хостинг Timeweb App Platform за запросы; переезд старых адресов без 301

Хостинг — фронтенд-приложение Timeweb Cloud App Platform, как и раньше. Оплата только за входящие запросы:
4,95 ₽ за 10 000. Простой ничего не стоит, это требование владельца. Автодеплой из `main` репозитория GitHub.
Проверено 2026-10-10 по документации Timeweb и ответам живых доменов:
- к одному приложению можно привязать любое количество доменов;
- если в сборке есть `404.html`, отдаётся он с кодом 404 (как у slides.aleksishmanov.ru); без него — `index.html` с кодом 200;
- каталог без слэша получает 308 на слэш;
- своих правил 301 нет.

Поэтому старые адреса переезжают так:
1. **Все старые домены** (`blog.`, `slides.`, `prompts.`, `call.`, `www.`) привязываются к этому же приложению.
2. **Скрипт `shared/host-redirect.js`** стоит первым в `<head>` каждой страницы портала и главной. На чужом хосте
   он делает `location.replace` на `https://aleksishmanov.ru` + новый путь: `blog./<slug>` → `/blog/<slug>/`,
   `slides./<id>/` → `/slides/<id>/`, `prompts./` → `/prompts/`, `call./` → `/call/`. Его же содержит `404.html`,
   поэтому неизвестные пути со старых доменов тоже уходят на основной хост.
3. **Страницы-переадресации** (`portal/src/pages/[...old].astro`) — для каждого старого адреса, который есть в
   публикациях: 30 статей Teletype (`/<slug>/`), рубрики `/+…/`, ленты `/data/rss/`, адреса старого WordPress-сайта,
   презентации. Мгновенный meta refresh плюс `canonical` на новый адрес. Google и Яндекс считают это постоянным переездом.
4. **`canonical`** на каждой странице указывает на aleksishmanov.ru.

Отклонено: Cloudflare Pages / Netlify / Vercel с настоящими 301 — нестабильная доступность из России и смена DNS-хостинга.
Свой VPS с nginx — регулярная плата за простой.

## Consequences

- Переключение доменов делает владелец в панелях: в Timeweb (домены приложения) и в SpaceWeb (DNS `blog.` — снять CNAME
  с Teletype). Пошагово — `.scratch/hub/spec.md`, раздел «Переключение доменов».
- Отдельные приложения `slides.` и `prompts.` в Timeweb после переключения не нужны.
- Новый старый адрес (например, найденный в старом посте) добавляется строкой в `[...old].astro` или в `old_urls` материала.
