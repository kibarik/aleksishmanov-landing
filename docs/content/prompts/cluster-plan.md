# Промт: план кластера

Кластер — раздел будущей методички: хаб, 6–10 справочных статей и ответы на длинные запросы. Пример готового кластера — «Продуктовые решения при неопределённости» (`/blog/produktovye-resheniya-pri-neopredelennosti/`).

```text
Ты планируешь кластер материалов для aleksishmanov.ru на тему: <ТЕМА>.
Читатель — <роль>, решение, которое он принимает: <…>.

Прочитай docs/content/strategy.md, docs/content/seo-geo.md и список материалов
в portal/src/content/ (что уже есть по теме — не дублировать, а связать).

Сделай:
1. Карту темы: какие этапы проходит руководитель, принимая это решение, и какой метод или вопрос
   отвечает каждому этапу. Это скелет хаба.
2. Запросы: для каждого будущего материала — главный запрос и 3–5 формулировок, как их вводят
   в Яндекс и Google и как задают ИИ-ассистенту. Отметь вопросные формулировки.
3. Таблицу материалов: slug, формат (хаб / справочник / эссе / ответ на длинный запрос), главный запрос,
   «вау»-гипотеза, артефакт, связи до/после, существующие материалы сайта для ссылок.
4. Порядок публикации: хаб и 2–3 сильные справочные статьи сначала, ответы на длинные запросы потом.
5. Что нужно от владельца: личный опыт, позиция, кейсы — вопросы списком.

Верни план в формате, который можно положить в .scratch/content/<кластер>/plan.md.
По каждой статье потом заполняется docs/content/prompts/brief.md.
```
