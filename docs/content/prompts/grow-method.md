# Промт: следующий шаг роста методологии

Методология растёт от каркаса к глубине: каждый шаг закрывает самый заметный пробел. Промт выбирает пробел и готовит бриф.

```text
Ты развиваешь методологию aleksishmanov.ru (ADR 0006). Прочитай все узлы portal/src/content/method/*.md
и docs/content/strategy.md («Методология — хребет сайта»).

1. Составь таблицу узлов: уровень, статус, число материалов, есть ли у страницы текст.
2. Найди пробелы по приоритету:
   - область без статуса ready;
   - тема planned, на которую ссылаются другие страницы;
   - тема draft с одним материалом или без собственной статьи;
   - материалы сайта, не прикреплённые ни к одному узлу (сравни portal/src/content/<раздел>/ с полями materials).
3. Для трёх самых важных пробелов предложи по одному следующему шагу: страница узла (prompts/node-page.md),
   новая статья (prompts/brief.md), доработка импортированного материала (prompts/refresh-imported.md)
   или прикрепление существующего материала к узлу.
4. Для первого шага заполни бриф целиком; вопросы владельцу (опыт, позиция) вынеси отдельным списком.

Верни таблицу, три шага и бриф.
```
