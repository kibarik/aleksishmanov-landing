Дата: 2026-10-10. Только чтение, ничего не скачивалось. Данные взяты со страниц моделей (через веб-запрос); метка «не проверено» — на странице данных нет.

## Вопрос
Какие свободные шахматные модели (CC0 или CC-BY, без NC) подходят для трёх чёрных глянцевых статичных фигур (конь + ещё две), ≤300 КБ после Draco, лёгкая версия для мобильных?

Треугольники и вес Poly Pizza и OpenGameArt-glTF без скачивания не видны; при скачивании: открыть в glTF-Transform / gltf.report, оценить число треугольников, прогнать `gltf-transform optimize --compress draco`.

## Процедурный вариант
- `LatheGeometry(points, segments, phiStart, phiLength)` — вращает профиль вокруг оси Y; x точек должен быть > 0 ([документация three.js](https://threejs.org/docs/pages/LatheGeometry.html)). Пешка, ладья (зубцы добавить отдельными боксами/вырезом), слон, ферзь (корона из профиля + сфера) получаются хорошо: 10–20 точек профиля, 32 сегмента desktop / 12–16 mobile.
- Вес ≈ 0 КБ (код, ~2–3 КБ), перекраска тривиальна (свой MeshPhysicalMaterial), количество сегментов регулируется пресетом.
- Конь — не тело вращения. Варианты: профиль головы в `Shape` + `ExtrudeGeometry` с фаской (bevel) на токарном постаменте; это даёт «плоского» коня, силуэт узнаваем, но выглядит грубо; сглаживание — через `bevelSegments`. Риск плохого коня — высокий (главный критерий). Трудоёмкость: пешка/ладья/ферзь ~полдня; конь с приличным профилем ~полдня–день подбора кривой.
- Документацию `ExtrudeGeometry` отдельно не открывал (параметры bevel — по памяти, не проверено).

## Рекомендация
Для главной фигуры (конь) взять готовый ассет, а не рисовать: сначала скачать [tunakron (CC0)](https://opengameart.org/node/157258) — самый лёгкий (264 КБ zip) и без требований по атрибуции, и посмотреть коня; запасные — [Nailfighter (CC0, 285 граней у коня)](https://nailfighter.itch.io/lowpoly-chess-set) через конвертацию FBX→glTF и [Jarlan Perez (CC BY 3.0, нужна ссылка на автора)](https://poly.pizza/m/fMIykP6ncx7). Остальные две фигуры (пешка, ладья или ферзь) собрать процедурно через Lathe — вес ≈ 0, единый вид. Если силуэт коня ни в одном наборе не устроит — процедурный конь через Extrude как последний вариант, с риском «грубости». Решение о коне принимать по скриншотам после скачивания, до этого оценка качества не проверена.

- Число треугольников у tunakron, Perez, Poly by Google, s1pierro; вес glTF каждой фигуры и итог после Draco.
- Наличие отдельных мешей и текстур в glTF tunakron.

- Лицензия на страницах Perez для ладьи/ферзя/пешки (проверены только конь и «Chess Set»).
- Параметры ExtrudeGeometry по документации.
