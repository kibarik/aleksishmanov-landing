# Стандарт материалов и ревью кластера «Продуктовые решения при неопределённости»

## Problem Statement

Статьи сайта должны погружать читателя в экспертизу Алексея: отвечать на вопрос, давать «вау» и артефакт, который уносят в команду, и возвращать читателя за инструментами, как это делает методология PAF. Для этого нужны три вещи: попадание в топ Яндекса и Google по целевым вопросам, цитирование в ИИ-ответах и текст, удобный человеку. В репозитории не было ни правил, ни промтов, ни проверки — каждый материал писался «как получится».

## Solution

Правила, промты и проверка живут в репозитории и используются ИИ-агентом при каждой статье:

| Что | Где |
| --- | --- |
| Стратегия: путь читателя, эталон PAF, кластеры, форматы, метрики | `docs/content/strategy.md` |
| Стандарт статьи: шесть обязательств, вклад автора, анатомия, «вау», артефакты, голос, оформление | `docs/content/article-standard.md` |
| Поиск и ИИ: правила Яндекса и Google, исследования GEO, мифы — с источниками | `docs/content/seo-geo.md` |
| Рубрика приёмки: 9 критериев, правило публикации | `docs/content/quality-rubric.md` |
| Промты: бриф, автор, ревьюер, доработка импорта, план кластера | `docs/content/prompts/` |
| Навык Claude Code | `.claude/skills/article/SKILL.md` |
| Автопроверка `npm run lint:content` и тест | `scripts/lint-content.mjs`, `tests/unit/lint-content.test.mjs` |
| Шаблон: `updated` → `dateModified` и «обновлено», подпись автора ведёт на «Обо мне» | `content.config.ts`, `schema.ts`, `[slug].astro` |

Главные выводы исследования (подробно и с источниками — `seo-geo.md`): отдельной «оптимизации под ИИ» нет — Алиса AI и AI Overviews берут источники из обычной выдачи; решают неширпотребная экспертиза автора (ЭПОС у Яндекса, non-commodity у Google), ответ в начале, источники, цитаты и числа; FAQ-сниппеты Google сняты у всех в 2026 году, llms.txt на выдачу не влияет.

### Что нашло ревью — повторяющиеся проблемы

1. **Нет голоса автора** во всех девяти статьях: грамотный синтез без опыта из первых рук. По Яндексу и Google это и отличает экспертный материал от ширпотреба. Закрывается только ответами владельца — `questions.md`.
2. **Факты «додуманы» поверх источника:** год издания без подтверждения, «независимо» вместо «параллельно», «три симптома» вместо четырёх, параметры STORM из статьи выданы за умолчания кода, формулировка Кляйна про «30% точнее» без оговорки, что исследование мерило число причин.
3. **Методическая ошибка:** в частых вопросах статьи о Хаббарде EVPI считался по проигрышным сценариям (365 тыс. ₽ вместо 93 тыс.). Исправлено, пересчитано аналитически и Монте-Карло.
4. **Совет статьи выдан за норму метода** («5–10 человек», «4–6 гипотез», «квартал работы») — теперь помечено «совет статьи».
5. **Лид-определение без ответа на запрос заголовка** и первые предложения разделов, которые нельзя процитировать без контекста.
6. **Артефакт описан, но не дан:** шаблоны без полей `<…>`, промты внутри текста — теперь шаблоны заполнимые, два промта вынесены в раздел «Промты» со ссылками в обе стороны.
7. **Английский жаргон** без русской пары (outcome, satisficing, confirmation bias).
