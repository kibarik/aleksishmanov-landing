# Редизайн 2026-10-25 — решения из интервью

Вход для `/to-spec`. Исходные 7 пунктов владельца — в начале сессии; здесь только принятые решения.

## Раунд 1 (принято целиком)

1. Предметы белой сцены — чистая декорация: убрать hover, плашку-ссылку («ИИ в бизнесе →») и переход по клику (`src/boot3d.js`, `src/content.js` chip, `body.is-prop-hover`).
2. Курсор-точка только на первом экране до ухода сцены; дальше на главной, в меню, футере и на всём портале — системный курсор.
3. Экран «Превращаю идеи…» («Обо мне», липкий): плюс одна тихая подсказка прокрутки внизу, без анимации кроме появления. «Смотреть кейсы» остаётся.
4. «Шапка» в п.3 = верхний блок страницы /cases/ (образец bersus portfolio); в п.7 = панель навигации портала `Header.astro` (образец Airtable). Две разные задачи.
5. /cases/: стопка кейсов уходит; список по bersus portfolio, страница кейса по bersus regulatory-agency. Поля `caseMaterial` не меняются.
6. Новый список и страница материала (белый фон, меню слева как IBM, «Автор», «Свежие материалы») — на все текстовые разделы (Блог, Разборы, Инструменты, Промты, Методология). Презентации и Кейсы — свои шаблоны.
7. «Свежие материалы» под статьёй: 3 последних того же раздела, без текущего.

## Раунд 2 (принято целиком; факты по референсам — `research/`)

1. Меню главной: сверху крупно два направления («Запуск продуктов», «ИИ в корпорациях») + строка «кому»; ниже Блог, Разборы, Инструменты, Кейсы, Обо мне; справа «Написать» + Telegram. Якорь «Чем полезен» уходит.
2. Анимация меню: WebGL-жидкость (`src/menuFluid.js`) заменяется белым кругом из угла кнопки (~0.6 с), затем побуквенное появление пунктов (как сейчас). Пирамида-око — в отдельной левой колонке на чистом фоне, никогда под текстом. Открытие по клику.
3. Подвал: тёмный (≈#0B0B0B, скругление сверху), один на главной и портале. Отменяет белый подвал из 80d6f9c.
4. Подвал: 3 колонки — ссылки (направления, разделы) | статичная эмблема-око | позиционирование, «Написать», профили, «© · RSS · llms.txt». Без canvas/шума/анимации; прокручиваемая карточка материалов из подвала главной уходит (`src/footer3d.js`, `src/footerNoise.js`).
5. Шапка портала: ISHMANOV | Направления ▾ (2 с описанием) | Материалы ▾ (Блог, Разборы, Инструменты, Промты, Презентации — с описанием) | Методология | Кейсы | Обо мне || чёрная «Написать». ~64px, sticky; на мобильном ☰ → тот же список группами. Подстрочник «Алексей Ишманов» убрать.
6. Страница материала: колонка 680px, 18/1.6, белый фон; липкое оглавление слева из H2 (если H2 ≥ 3), на узких экранах — горизонтальная строка; цитата Markdown → выносная цитата, первый абзац → лид. Без новой разметки контента.
7. Карточка автора: серая, фото (пока нет — монограмма «АИ», владелец пришлёт фото), имя, позиционирование, о себе, профили.
8. Ряд после статьи: Автор | Свежие материалы (3) | Подписаться в Telegram.
9. /cases/: заголовок, вступление, кейсы строками (заголовок-результат, направление, годы, 2 цифры), без картинок. Страница кейса белая, 680px, цифры крупными блоками, без видео. Показ владельцу — локально с черновиками.
10. `/prototype` пропускаем; приёмка — вся локальная сборка целиком.
