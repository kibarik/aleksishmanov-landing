# 04: Шапка портала по образцу Airtable

**What to build:** На всех страницах портала закреплённая шапка ~64px: слева ISHMANOV без подстрочника; «Направления ▾» (2 пункта, у каждого строка описания), «Материалы ▾» (Блог, Разборы, Инструменты, Промты, Презентации, у каждого строка описания); прямые «PO System» (`/po-system/`), «Кейсы», «Обо мне»; справа одна чёрная кнопка «Написать». «Методологии» в шапке нет. Текущий раздел отмечен. Панели открываются кликом (и наведением на desktop), закрываются Escape и кликом мимо; раскрывающие пункты — кнопки с `aria-expanded`. На телефоне ☰ открывает тот же список группами. Без JS все адреса есть в HTML. Описания — в данных сайта. Спека: `../spec.md` (истории 30–40); факты: `../research/airtable-header.md`; решения: `../decisions.md` раунд 2, п. 5 и выбор «PO System».
