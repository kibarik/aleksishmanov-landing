# 06: Страница материала — оглавление слева и типографика длинного текста

**What to build:** Текстовый материал (Блог, Разборы, Инструменты, Промты) читается как длинная экспертная статья IBM: белый фон, колонка текста 680px, кегль 18, межстрочный 1.6. Слева липкое оглавление из подзаголовков H2 — показывается, если их не меньше трёх; при прокрутке отмечен текущий пункт; на узких экранах оглавление — горизонтальная строка под шапкой. Первый абзац — лид, цитаты Markdown — крупные выносные блоки. Новой разметки контента нет. Markdown-копия, разметка Article и хлебные крошки сохраняются. Спека: `../spec.md` (истории 42–47, 53); факты: `../research/ibm-case-study.md`; решения: `../decisions.md` раунд 2, п. 6.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] Чистая функция оглавления: из заголовков материала → пункты H2 или пусто при < 3; юнит-тест
- [ ] E2E: оглавление есть у материала с ≥ 3 H2 и отсутствует у материала с меньшим числом; активный пункт меняется при прокрутке; на узком экране оглавление горизонтальное
- [ ] Ширина колонки текста ≈ 680px на desktop; лид и выносная цитата отличаются оформлением
- [ ] `/blog/<slug>.md` и JSON-LD Article не сломаны
- [ ] Оставить в шаблоне явное место под ряд после материала (задача 07)
- [ ] Стили — в компонентах страницы материала, не в общем файле стилей
