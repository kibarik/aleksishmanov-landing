# 09: Золотые снимки главной и полный прогон

**What to build:** После изменений главной (курсор, меню, подвал) затронутые золотые скриншоты обновлены один раз, осознанно, и все наборы зелёные на интеграционной ветке. Отдельная задача, потому что золотые снимки — бинарные файлы и параллельные обновления не сливаются.

**Blocked by:** 01, 02, 03

**Status:** resolved

- [x] `npm run test:update-golden` выполнен; в отчёте перечислено, какие снимки изменились и почему (меню, подвал, курсор)
- [x] Зелёные: `npm run test:unit`, `npm run test:portal`, `npm test`
- [x] Падения, не связанные со снимками, — исправлены или вынесены в отчёт с причиной

## Результат

Золотые снимки (`tests/e2e/golden/*.png`) обновлять не пришлось: `__capturePng` снимает только буфер WebGL, а меню, подвал, курсор и подсказка — DOM/CSS и в кадр не попадают. Все наборы зелёные без обновления: лендинг 40 passed / 4 skipped (prod-*), портал 45 passed, unit 33 pass / 1 fail (import-sources — нет ../sources на этой машине, известно). `golden-states.desktop` ×5 подряд зелёный — единичное падение было флейком от параллельной нагрузки.
