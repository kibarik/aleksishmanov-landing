# Редизайн 2026-10: спокойная навигация, один подвал, читаемые материалы

Решения интервью — `decisions.md` (рядом), факты по референсам — `research/`. Словарь — `CONTEXT.md`
(Курсор-точка, Меню, Шапка портала, Подвал, Карточка автора, Свежие материалы, Список и страница кейса).
Ветка интеграции — `feat/redesign-2026-10`.

## Problem Statement

Знакомый, открыв главную, натыкается на белой сцене на предметы, которые реагируют на мышь и выкидывают плашку
«ИИ в бизнесе →» поверх заголовка. Ниже, на липком экране «Превращаю идеи в работающие бизнес-платформы», он теряет
курсор (системный скрыт по всей странице, а точка-курсор на тёмном фоне не видна) и не понимает, что страницу надо
листать. Меню открывается поверх шумного анимированного фона, на котором пункты не читаются, а сам список пунктов
плоский и ничего не подсказывает. Подвал главной анимирован (3D и шум) и не похож на подвал портала.

Читатель, пришедший на материал из поиска, видит шапку портала из восьми ссылок подряд и подстрочника, страницу
«Кейсы» с перегруженным верхним блоком и стопкой слайдов, а статья — длинный текст без оглавления, без акцентов,
без блока «кто автор» и без того, что читать дальше.

## Solution

Главная остаётся wow только на первом экране: курсор-точка живёт до ухода сцены, дальше системный курсор; предметы
белой сцены — декорация. Липкий экран «Обо мне» получает тихую подсказку прокрутки. Меню становится «выбери свою
задачу»: два направления крупно, разделы ниже, белый круг из угла вместо шумного фона, эмблема-око в своей колонке.

На всех страницах (главная и портал) один тёмный статичный подвал. Портал получает шапку по образцу Airtable: два
выпадающих пункта с описаниями и несколько прямых ссылок. Текстовые материалы читаются как длинные экспертные
статьи IBM: колонка 680px, липкое оглавление слева, выносные цитаты, лид; в конце — карточка автора, «Свежие
материалы» и подписка на Telegram. Кейсы — спокойный список и страница кейса по образцу bersus portfolio.

## User Stories

### Главная: первый экран и «Обо мне»

1. As a знакомый, I want предметы белой сцены не реагировать на наведение, so that ничего не перекрывает заголовок.
2. As a знакомый, I want клик по предмету белой сцены ничего не делать, so that я не ухожу со страницы случайно.
3. As a знакомый, I want видеть курсор-точку на тёмной сцене, переходе и белой сцене, so that wow первого экрана сохраняется.
4. As a знакомый, I want после ухода сцены видеть свой системный курсор, so that я всегда знаю, где мышь.
5. As a знакомый, I want системный курсор на липком экране «Обо мне», so that тёмная секция не прячет мышь.
6. As a знакомый, I want системный курсор над подвалом и в открытом меню, so that я точно попадаю по ссылкам.
7. As a знакомый, I want вернуться прокруткой наверх к сцене и снова увидеть точку, so that первый экран ведёт себя одинаково.
8. As a знакомый, I want на липком экране «Обо мне» видеть тихую подсказку прокрутки внизу, so that я понимаю, что страница продолжается.
9. As a знакомый, I want подсказка прокрутки исчезала, когда на экран наезжает следующий блок, so that она не мешает дальше.
10. As a знакомый, I want кнопка «Смотреть кейсы» оставалась на экране «Обо мне», so that короткий путь в кейсы не пропал.
11. As a знакомый на телефоне, I want всё как раньше с системным курсором и без точки, so that ничего не сломалось.

## Implementation Decisions

- **Курсор.** Модуль курсора включает точку и скрывает системный курсор только пока сцена не ушла (состояние ухода
  сцены уже есть в виртуальном скролле); после ухода и при возврате выше — переключение классом на `body`.
  Правило `cursor: none` больше не глобальное. Фолбэк без WebGL — сразу системный курсор.
- **Предметы белой сцены.** Убираются hover-подсветка, класс `is-prop-hover`, плашка-ссылка из контента и обработчик
  клика; предметы остаются в сцене как есть.
- **Подсказка прокрутки «Обо мне».** Статичная подпись внизу липкого экрана, появляется вместе с экраном, прячется,
  когда наезжает следующий блок. Существующий тест подсказки прокрутки — prior art.
- **Меню.** Данные меню в контенте лендинга перестраиваются: `directions` (2, с подписью «кому»), `pages` (Блог,
  Разборы, Инструменты, Кейсы, Обо мне), сбоку контакт и Telegram; якорь «Чем полезен» уходит. WebGL-жидкость меню
  удаляется; фон — белый круг (CSS `clip-path: circle()` от угла кнопки, ~0.6 с), затем существующая побуквенная
  анимация. Эмблема — в своей колонке сетки панели. Открытие только по клику (зона наведения в углу больше не открывает).
  `prefers-reduced-motion` — без анимации.
- **Подвал — один источник.** Разметка подвала строится одной чистой функцией в `shared/` из общих данных (направления,
  разделы, профили, позиционирование, контакт). Портал вставляет её в базовый лейаут, главная — при сборке (так же,
  как главная уже получает данные портала при сборке). Данные берутся из портальных `site.ts`/`materials.ts`, чтобы
  не было второй копии. Удаляются 3D-подвал, шум подвала и прокручиваемая карточка материалов главной. Подвал тёмный
  (≈#0B0B0B, скругление сверху ~48–62px), три колонки, на мобильном — столбиком. `/po-system/` (отдельный подсайт)
  этот подвал не использует.
- **Шапка портала.** Компонент шапки переписывается: бренд, две кнопки-раскрывашки с панелями (группа, пункт =
  заголовок + строка описания), прямые ссылки «PO System» (`/po-system/`), «Кейсы», «Обо мне», кнопка «Написать».
  Описания пунктов — в `site.ts`. «Методология» из шапки уходит (ADR 0006 отклонён, /method/ переезжает в подсайт).
  Без JS панели раскрываются через `<details>` или ссылки на разделы видны в мобильном списке — главное, чтобы все
  адреса были в HTML. Высота ~64px, `position: sticky`.
- **Список материалов.** Общий шаблон списка раздела перестраивается в одну колонку (~540–680px) без картинок:
  заголовок, метки направлений, анонс, время чтения и дата.
- **Страница материала.** Общий шаблон `[section]/[slug]` получает раскладку: оглавление слева (липкое, из H2 —
  заголовки берутся из `headings` Astro, показывается при ≥3), колонка текста 680px. Подсветка активного пункта —
  маленький скрипт на IntersectionObserver. Лид = первый абзац (CSS), выносная цитата = `blockquote` (CSS). Новой
  разметки контента нет. Чистая функция `toc(headings)` → список пунктов или пусто.
- **Ряд после материала.** Карточка автора (данные — `site.ts`: имя, позиционирование, «о себе», профили, фото или
  монограмма), «Свежие материалы» и «Подписаться в Telegram» (ссылка на основной канал из профилей). Чистая функция
  `freshMaterials(all, current, n = 3)` в `materials.ts`: тот же раздел, без текущего, без черновиков, по дате убыв.
- **Кейсы.** Компонент стопки кейсов и его скрипт удаляются, `/cases/` рендерит список строк; страница кейса — новый
  шаблон по полям `caseMaterial` (схема не меняется). Пустое состояние — одна строка и ссылка «Написать».
- **Презентации** сохраняют свой шаблон; получают новую шапку и подвал через общий лейаут.

## Testing Decisions

- Хороший тест проверяет то, что видит посетитель в собранном сайте (роли, тексты, адреса, видимость, вычисленный
  `cursor`), а не внутренние классы и структуру модулей.
- **Портал — Playwright по собранному `dist/`** (`npm run test:portal`, `tests/e2e/*.portal.spec.js`; prior art —
  `portal.portal.spec.js`, `cases.portal.spec.js`): шапка (группы, описания, «PO System», текущий раздел, Escape,
  мобильный ☰), подвал (одинаковый на главной и портале, три группы ссылок, нет canvas), страница материала
  (оглавление при ≥3 H2 и его отсутствие при меньшем, активный пункт при прокрутке, карточка автора, три свежих
  материала без текущего, Telegram), список кейсов и страница кейса с черновиками, пустое состояние.
- **Главная — Playwright desktop/mobile/no-webgl** (prior art — `menu.*.spec.js`, `footer.*.spec.js`,
  `cursor-parallax.*.spec.js`, `scroll-hint.desktop.spec.js`, `intro-section.desktop.spec.js`): точка видна на
  сцене и системный курсор после ухода сцены (вычисленный `cursor` над «Обо мне» и подвалом ≠ `none`); наведение на
  предмет белой сцены не даёт плашки и `pointer`; подсказка прокрутки на «Обо мне»; меню — порядок групп, открытие по
  клику, а не по наведению, эмблема не пересекается с прямоугольниками пунктов, Escape и возврат фокуса; подвал без
  canvas. Золотые скриншоты, затронутые меню и подвалом, обновляются осознанно (`test:update-golden`).
- **Юниты (`node --test tests/unit`)** только на чистые функции: `freshMaterials`, `toc`, функция разметки общего
  подвала (содержит все направления, разделы и профили). `case-stack.test.mjs` удаляется вместе со стопкой.

## Out of Scope

- Тексты позиционирования и теглайна (ждут решения владельца).
- Новая разметка акцентов в Markdown (блоки «цифра-акцент», callout) — отдельная задача, когда статьи начнут их использовать.
- Фото автора — владелец пришлёт; до этого монограмма.
- Подсайт `/po-system/`, переезд на Dokploy и закрытие `/method/` (ADR 0007, отдельная работа).
- Шаблон «Презентаций» и страницы направлений, кроме общей шапки и подвала.
- Вёрстка белой и тёмной сцены, лоадер, путь посетителя до ухода сцены.
