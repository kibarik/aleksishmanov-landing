# 05: Каркас: как отдавать полный текст и сохранить 3D-сцену

**Type:** prototype
**Status:** resolved
**Blocked by:** 01

**Вопрос.** Сейчас одна страница на vanilla Vite, текст рисует скрипт. Нужны десятки статических страниц
с полным текстом в HTML из Markdown, а главная — тот же 3D-путь посетителя без регрессий.

**Варианты.**
- Astro: страницы из Markdown-коллекций, 3D-сцена — остров на главной (существующие `src/*.js` без переписывания).
- Многостраничный Vite + свой генератор страниц из Markdown.
- Другое, если 01 ограничит (например, площадка с готовым генератором).

**Рамка (решение владельца):** без CMS; контент — файлы в git, пишутся с ИИ-агентом; на выходе только статика.
Посмотреть, на чём собран `prompts.` (выгрузка Next в `sources/prompts-site`) — понравившаяся модель.

**Критерии.** Полный текст и метатеги в HTML без JS; главная проходит текущие E2E и золотые кадры; сборка остаётся статикой;
добавить материал = положить Markdown-файл; размер бандла главной не растёт; прод-проверки (`test:prod`) работают для многих страниц.

**Что нужно на выходе.** Прототип в ветке `prototype/hub-framework`: главная со сценой + одна статья из `aleks-catalog`,
прогон E2E; решение — ADR.

## Answer

Astro 5 для портала, лендинг остаётся на Vite (разделение стеков — предложение владельца). Сравнение Astro / Next export / Eleventy / Hugo — `docs/adr/0002-portal-landing-plus-astro.md`. Прототип не понадобился: сборка сразу сделана в ветке `feat/portal`.
