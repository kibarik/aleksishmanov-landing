# Портал aleksishmanov.ru: все материалы на одном сайте

## Problem Statement

Материалы Алексея Ишманова были разложены по десяти площадкам: блог на Teletype, три Telegram-канала, отдельные
поддомены для промтов, презентаций и страницы звонка. На самом aleksishmanov.ru почти не было текста для поиска.
По запросу «Алексей Ишманов» сайт не находился, а старые ссылки (например, на статью про SGR) открывали лендинг.

## Solution

aleksishmanov.ru — единственный сайт. Главная остаётся 3D-лендингом, под ним портал: разделы по типам материалов
и две страницы направлений. Всё собирается в статику и хостится там же, на Timeweb, с оплатой за запросы.
Старые домены привязываются к тому же приложению и ведут на новые адреса. Решения — ADR 0002–0004, словарь — `CONTEXT.md`.

## Сценарий приёмки (HowToDemo)

Каждый шаг закрыт автоматическим тестом в `tests/e2e/portal.portal.spec.js` (`npm run test:portal`) или в наборе лендинга (`npm test`).

1. aleksishmanov.ru: 3D-путь посетителя как раньше. Под ним без JS в HTML видны имя, позиционирование, две карточки направлений, «Свежие материалы» и разметка Person.
2. Меню главной и шапка портала ведут в разделы «Блог», «Разборы», «Инструменты», «Промты», «Презентации», «Кейсы», «Обо мне».
3. Любая статья Teletype открывается по `/blog/<slug>/` с полным текстом без JS, с canonical и разметкой Article. Проверены все 30.
4. Старые адреса ведут на новые: `blog.…/<slug>`, `slides.…/<id>/`, `prompts.…/prompts/<slug>/`, `prompts.…/`, а на корне — `/<slug>/`, `/+рубрика/`, `/data/rss/`, адреса WordPress.
5. Несуществующий адрес — страница 404 с кодом 404.
6. Есть `sitemap.xml` (с главной), `robots.txt`, RSS, `llms.txt` и Markdown-копии. Title начинается с «Алексей Ишманов».
7. Внутренние ссылки всех страниц ведут на существующие файлы. Презентации открываются без 404 на ресурсах.
8. На ширине 390 px нет горизонтальной прокрутки.
9. Все E2E зелёные.

## Переключение доменов (делает владелец, после выкатки main)

Порядок: сначала новый адрес проверен, только потом переключение. Откат — вернуть домен старому приложению или DNS-запись.

1. **Timeweb → App Platform → приложение aleksishmanov.ru → «Настройки».** Проверить: Node.js 20 или новее,
   команда сборки `npm run build`, директория сборки `dist`. После деплоя открыть https://aleksishmanov.ru/blog/.
2. **Домены.** В том же приложении «Домены → Редактировать» добавить `slides.aleksishmanov.ru`, `call.aleksishmanov.ru`,
   `prompts.aleksishmanov.ru` и `www.aleksishmanov.ru`. Если домен привязан к старому приложению (slides, prompts, call),
   сначала отвязать его там. Каждая привязка запускает повторный деплой.
3. **DNS в SpaceWeb** (MX и SPF почты Beget не трогать):
   - `slides`, `call` уже смотрят на 178.209.127.53 — менять ничего не нужно, если панель Timeweb не подскажет другой адрес;
   - `prompts`: A-запись 92.246.76.92 заменить на адрес из подсказки Timeweb для приложения aleksishmanov.ru;
   - `www`: добавить A-запись на тот же адрес;
   - `blog`: удалить CNAME `domains.teletype.in`, добавить A-запись на тот же адрес, затем привязать `blog.aleksishmanov.ru` в Timeweb (как в шаге 2).
4. **Проверка:** `bash scripts/check-domains.sh`. Каждый старый домен должен отдать страницу со скриптом перевода на aleksishmanov.ru.
5. **Teletype:** в настройках блога снять свой домен. Статьи можно оставить или скрыть: canonical теперь на сайте.
6. **Остановить** старые приложения Timeweb (slides, prompts, call) после проверки. **Архивировать** репозитории
   `kibarik/slides-catalog`, `kibarik/aishmanov-landing`, `kibarik/ai-oxudevelopment`.
7. **Поиск:** добавить сайт в Яндекс Вебмастер и Google Search Console, отправить `https://aleksishmanov.ru/sitemap-index.xml`.
8. **Telegram:** в описание каждого канала — имя и ссылку на сайт (документ архитектуры, раздел «Telegram-каналы»).
9. **Домен** оплачен до 2026-12-16 (RU-CENTER) — продлить.
