# 03: Кнопка Ask Ishmanov AI

**What to build:** после появления теглайна знакомый видит под пьедесталом кнопку «Ask Ishmanov AI», такая же кнопка есть в шапке; обе ведут по ссылке из модуля контента (сейчас личка t.me/kibarik, позже бот), открываются в новой вкладке.

**Blocked by:** 02 (Модуль контента)

**Status:** done

- [x] Кнопка под пьедесталом появляется вместе с теглайном на обоих пресетах, в стиле референса (капсула, стрелка), не перекрывает пьедестал на мобильном 390×844
- [x] Кнопка в шапке видна с момента появления навигации и в белой, и в тёмной теме
- [x] Обе кнопки берут href из одной константы контента; замена на бота — правка одной строки
- [x] Кнопка на сцене уезжает вместе со сценой при уходе, не остаётся висеть над контентом
- [x] E2E: после белой сцены обе кнопки видимы, href совпадает с контентом

## Comments

- Реализовано: `#ask-scene` внутри `#hero` (капсула со стрелкой, класс `ask--visible` вместе с теглайном; на мобильном `bottom: 3.5vh` — ниже пьедестала, чей низ на ~86% кадра; на десктопе капсула перекрывает основание пьедестала, как у референса) и `#ask-nav` в `.nav__right` рядом с кнопкой меню; обе берут `href`/подпись из `content.ask` в `main.js`. Уход сцены: кнопка в `#hero`, уезжает с ним. E2E `tests/e2e/ask-button.*.spec.js`; хелпер `rectOf` — `boundingBox()` в эмуляции Pixel 7 врёт из-за DPR.
- Попутно: кнопка меню была невидима на тёмной сцене (`button` не наследует `color`) — добавлен `color: inherit`; подсказка «scroll down» на мобильном опущена до 9.5vh, чтобы не липла к кнопке в шапке.
- Наблюдение для тикета 11: при параллельном рендере сцены в другой вкладке (превью) прогон замедляется в 1.5–2 раза и два теста флакают по таймаутам; без нагрузки 8/8 стабильно.
