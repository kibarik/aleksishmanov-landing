# 07: Фолбэк без WebGL

**What to build:** знакомый без WebGL видит вместо чёрного экрана статичный кадр белой сцены (webp), обычную страницу со всеми секциями и светлую шапку; лоадер не появляется, бандл three не грузится. Кадр генерируется из самой сцены командой и лежит в репозитории.

**Blocked by:** 02 (Модуль контента), 04 (Секции после сцены)

**Status:** ready-for-agent

- [ ] Инлайн-проверка в head: `getContext('webgl')` и `webgl2` с `failIfMajorPerformanceCaveat`; при провале атрибут на html, бандл сцены не импортируется
- [ ] Первый экран показывает webp белой сцены (два размера: десктоп и мобильный, srcset), страница скроллится нативно, шапка в светлой теме, кнопка Ask видна
- [ ] Скрипт генерации кадра: поднимает страницу, доводит до белой сцены, захватывает кадр через `__app.capture()`, сохраняет webp; README описывает команду
- [ ] Кадр обновлён после финальных текстов имени и теглайна
- [ ] E2E: проект no-WebGL видит картинку, не видит canvas и лоадер, секции присутствуют
