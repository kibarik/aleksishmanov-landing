## Comments

- Золотые кадры: `dark-desktop`, `white-desktop`, `dark-mobile`, `white-mobile` — тесты `golden-states.*.spec.js`, три прогона подряд стабильны.
- Отступление: кадров ухода сцены нет. `__capturePng` снимает буфер WebGL, а уход сцены — это CSS-трансформ канваса и смена потока: кадры `leave-*` отличались от `white-*` на сотые доли score при пороге 4, то есть прошли бы и с полностью выключенным параллаксом. Геометрия ухода проверяется в `scene-leave.*.spec.js`.
- Отступление: пик глитча золотым кадром не фиксируется. Эффект шумит по времени, кадр недетерминирован (score гулял 12–25 при пороге 12). Вместо него структурная проверка: в середине перехода кадр сильно отличается от золотого кадра тёмной сцены (`scoreAgainstGolden > 8`).
- Кроссбраузерность: добавлены проекты `webkit` и `firefox` (путь посетителя). Firefox зелёный, включая сравнение золотого кадра. WebKit не стартует на macOS 14 с Playwright 1.63: `Protocol error (Page.overrideSetting): Unknown setting: PushAPIEnabled` — установленная сборка WebKit для этой ОС старше ожидаемой, `--force` переустановка не помогла. Проект оставлен в конфиге для другой машины; мобильный Safari по той же причине не проверен.
- Сборка: `npm run test:build` (`PREVIEW=1`) прогоняет desktop, mobile и no-webgl против `vite build` + `vite preview` — 19/19 зелёных.
- README дополнен: запуск, тесты, прогон по сборке, золотые кадры, генерация фолбэк-кадра, замер производительности, кроссбраузерные ограничения. В `spec.md` добавлена сверка user stories с перечнем невыполненного.

Мета-теги и Open Graph на месте, счётчика Метрики в исходнике страницы нет (подключается после первой отрисовки).
