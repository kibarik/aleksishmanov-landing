# 01: Каркас E2E на Playwright

**What to build:** посетитель-робот проходит путь до белой сцены на десктопе и телефоне, и проект получает команду `npm test`, которая это подтверждает. Тесты крутят колесо или свайпают, ждут окончания prelude, читают прогресс шагов через хук на чтение и сравнивают кадр белой сцены с золотым через существующий `__compare()` по порогу score, не попиксельно.

**Blocked by:** None (can start immediately)

**Status:** done

- [x] Установлен `@playwright/test`, конфиг с тремя проектами: desktop 1440×900, mobile 390×844 с эмуляцией touch и mobile user agent, no-WebGL (флаги запуска браузера, отключающие WebGL)
- [x] Хелперы: дождаться prelude, прокрутить N тиков колеса / свайпов, прочитать прогресс и released, захватить кадр; хуки `window.__sticky` и `window.__app` используются только для чтения
- [x] Тест «путь до белой сцены»: desktop проходит init → тёмная сцена → into-white → белая сцена (640), mobile проходит 260 → 1053; после свапа тело в светлой теме, теглайн виден
- [x] Золотые кадры белой сцены для desktop и mobile лежат в репозитории, сравнение через `__compare()` с порогом, тест падает при превышении
- [x] `npm test` поднимает dev-сервер сам (webServer в конфиге) и проходит зелёным локально
- [x] Ручные скрипты этой сессии больше не нужны: README ссылается на `npm test`
