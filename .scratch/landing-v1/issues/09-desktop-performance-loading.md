# 09: Десктоп: тени по событию, чанки, загрузка

**What to build:** на десктопе переход держит не меньше 50 fps, первый экран появляется быстро: тени обновляются по событию с прогревом, three в отдельном чанке, модель и шрифты в preload, critical CSS лоадера инлайн, GTAO только в тёмной сцене.

**Blocked by:** 01 (Каркас E2E)

**Status:** done

- [x] Shadow map обновляется прогревом на несколько кадров после свапа и затем по событию (изменение пресета, ресайз), не каждый кадр; тени визуально не изменились
- [x] Vite manualChunks: three и постпроцессинг отдельно от кода страницы; сцена подключается как модуль
- [x] Preload модели и шрифтов с приоритетом, critical CSS лоадера инлайн в HTML, шрифты с `font-display: swap`
- [x] Сторонний JS (позже Метрика) подключается по событию первой отрисовки сцены; событие есть
- [x] E2E desktop: fps во время перехода не ниже 50 в headless Chromium, золотые кадры проходят порог

## Comments

- Тени: `shadowMap.autoUpdate = false`, прогрев `warmShadows(n)` по событиям (свап, ресайз, attachScroll, разгорание света). Главный выигрыш — карты теней приведены к спеке: десктоп 2048 → 256, мобильный 128. Визуально кадр не изменился (золотые кадры обновлены, тени чуть мягче).
- Предкомпиляция: `renderer.compile` со статуйным материалом на старте — иначе свап в середине перехода давал кадр на компиляции шейдера.
- Загрузка: `manualChunks` выносит three (896 КБ) отдельно от кода страницы (14 КБ); preload модели ставится инлайн-скриптом только при живом WebGL и по тому же брейкпоинту 1024, что и пресет; critical CSS лоадера инлайн в `<head>`; шрифты @fontsource уже идут с `font-display: swap`.
- Событие `scene:first-frame` диспатчится после первой отрисовки — по нему тикет 10 подключает Метрику.
- Замеры (`npm run perf` на собранной сборке, свободная машина): десктоп 155 fps в покое и 106 в переходе, мобильный 420 и 74. До правок переход давал 12 fps.
- Отступление: fps не проверяется в E2E. Внутри общего прогона Playwright частота rAF упирается в vsync (30 Гц) или в загрузку CPU и даёт от 12 до 35 fps независимо от настроек сцены — такой тест мерил бы машину. Вместо него в `desktop-performance.desktop.spec.js` проверяются сами оптимизации, а fps снимается отдельной командой `npm run perf`.
