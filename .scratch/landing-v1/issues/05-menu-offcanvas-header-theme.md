# 05: Меню-оффканвас и тема шапки

**What to build:** знакомый открывает меню кнопкой в шапке, видит якоря «Обо мне», «Проекты», «Написать» и внизу ссылки на ресурсы; клик по якорю плавно скроллит к секции и закрывает меню. Шапка переключает цвет с белого на тёмный при свапе в белую сцену и остаётся читаемой на всех секциях.

**Blocked by:** 04 (Секции после сцены)

**Status:** ready-for-agent

- [ ] Кнопка меню открывает оффканвас с анимацией в стиле референса; закрытие по крестику, клику вне и Escape
- [ ] Якоря ведут к секциям; если сцена ещё липкая, клик по якорю сначала отпускает сцену, потом скроллит
- [ ] Ресурсы внизу меню берутся из модуля контента
- [ ] Шапка меняет тему при свапе и обратно при возврате в тёмную сцену
- [ ] Меню работает с клавиатуры и на touch
- [ ] E2E: открыть меню, клик по «Проекты», секция проектов в зоне видимости, меню закрыто
