# 05: Меню-оффканвас и тема шапки

**What to build:** знакомый открывает меню кнопкой в шапке, видит якоря «Обо мне», «Проекты», «Написать» и внизу ссылки на ресурсы; клик по якорю плавно скроллит к секции и закрывает меню. Шапка переключает цвет с белого на тёмный при свапе в белую сцену и остаётся читаемой на всех секциях.

**Blocked by:** 04 (Секции после сцены)

**Status:** done

- [x] Кнопка меню открывает оффканвас с анимацией в стиле референса; закрытие по крестику, клику вне и Escape
- [x] Якоря ведут к секциям; если сцена ещё липкая, клик по якорю сначала отпускает сцену, потом скроллит
- [x] Ресурсы внизу меню берутся из модуля контента
- [x] Шапка меняет тему при свапе и обратно при возврате в тёмную сцену
- [x] Меню работает с клавиатуры и на touch

## Comments

- Реализовано: `src/menu.js` строит оффканвас из контента (`content.menu.anchors` — «Обо мне»/«Проекты»/«Написать», ресурсы внизу из `content.resources`). Закрытие: крестик, оверлей, Escape (перехват до обработчика липкого скролла), переход по якорю. Фокус уходит на крестик при открытии и возвращается на кнопку меню при закрытии.
- В `stickyScroll` добавлены `release()` (клик по якорю отпускает сцену до скролла) и `setPaused()` (пока меню открыто, жесты не двигают сцену).
- Тема шапки уже переключалась классом `is-light` при свапе — добавлен тест, который это фиксирует (белая на тёмной сцене, тёмная на белой).
- Флак из тикета 03 закрыт: `leaveScene` повторяет жест до release (под нагрузкой один свайп не доезжал).
