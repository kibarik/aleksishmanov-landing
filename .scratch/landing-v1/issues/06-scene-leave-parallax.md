# 06: Уход сцены с задержкой персонажа

**What to build:** после белой сцены следующий жест вниз отдаёт нативный скролл; сцена уезжает вверх, но персонаж отстаёт от контента на протяжении первого экрана высоты и затем догоняет, создавая глубину. Докрутив страницу до верха и крутнув ещё раз вверх, знакомый возвращается в липкий режим на белой сцене и может пройти переход назад до тёмной.

**Blocked by:** 04 (Секции после сцены)

**Status:** done

- [x] При уходе сцены контейнер персонажа движется медленнее контента (коэффициент меньше единицы) на первом экране высоты, потом синхронизируется; имя, теглайн и кнопка Ask уезжают вместе с контентом
- [x] Без рывка в момент отпускания скролла: положение сцены непрерывно
- [x] Возврат: на scrollY = 0 жест вверх включает липкий режим, прогресс на белой сцене, жесты вверх ведут к тёмной сцене
- [x] На мобильном то же через свайпы
- [x] E2E: последовательность прогрессов 640 → released → scrollY растёт → возврат → 640 → 440 → 200 на десктопе; аналог на мобильном

## Comments

- Реализовано: в `main.js` канвас получает `translate3d` на `(1 - 0.7) * min(scrollY, innerHeight)` — персонаж отстаёт на первом экране, дальше смещение не растёт и сцена идёт с контентом синхронно. Теглайн и кнопка Ask лежат в потоке `#hero` и уезжают вместе с контентом. Обработчик scroll — passive, через rAF; при возврате в липкий режим transform снимается, поэтому рывка нет (наверху смещение равно нулю).
- Мобильный возврат не работал вовсе: `reengage` слушал только колесо. Добавлена протяжка вниз на `scrollY <= 0` (`reengageTouchPx: 40`), остаток жеста после возврата игнорируется — иначе тот же свайп утаскивал прогресс назад с 1053 до 843.
- E2E `tests/e2e/scene-leave.*.spec.js`: отставание канваса, синхронность оверлеев, отсутствие рывка наверху, возврат 640 → 440 → 200 на десктопе и 1053 на мобильном.
