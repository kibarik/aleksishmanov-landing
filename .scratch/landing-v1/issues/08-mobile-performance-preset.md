# 08: Мобильный пресет производительности

**What to build:** на телефоне сцена грузит облегчённую модель и рендерится с настройками референса: DPR 1–1.5, без GTAO и глитча, тени 128; переход не дёргается и не греет устройство.

**Blocked by:** 01 (Каркас E2E)

**Status:** ready-for-agent

- [ ] Отдельный файл модели для мобильного пресета: децимация до 100–200k треугольников (gltf-transform simplify), Draco; визуально силуэт и складки сохранены
- [ ] Загрузчик выбирает модель по пресету; десктоп грузит текущую
- [ ] Мобильный пресет: DPR clamp 1–1.5, GTAO выключен, глитч-пасс не добавляется в композер, shadow map 128, antialias по образцу референса (без MSAA, SMAA через композер при необходимости)
- [ ] Размер мобильной модели не больше 1 MB
- [ ] E2E mobile: грузится облегчённый файл (перехват запроса), fps во время перехода не ниже 40 в headless Chromium; золотые кадры мобильной белой сцены обновлены и проходят порог
