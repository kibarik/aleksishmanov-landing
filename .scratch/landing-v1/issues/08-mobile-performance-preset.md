# 08: Мобильный пресет производительности

**What to build:** на телефоне сцена грузит облегчённую модель и рендерится с настройками референса: DPR 1–1.5, без GTAO и глитча, тени 128; переход не дёргается и не греет устройство.

**Blocked by:** 01 (Каркас E2E)

**Status:** done

- [x] Отдельный файл модели для мобильного пресета: децимация до 100–200k треугольников (gltf-transform simplify), Draco; визуально силуэт и складки сохранены
- [x] Загрузчик выбирает модель по пресету; десктоп грузит текущую
- [x] Мобильный пресет: DPR clamp 1–1.5, GTAO выключен, глитч-пасс не добавляется в композер, shadow map 128, antialias по образцу референса (без MSAA, SMAA через композер при необходимости)
- [x] Размер мобильной модели не больше 1 MB
- [x] E2E mobile: грузится облегчённый файл (перехват запроса), золотые кадры мобильной белой сцены обновлены и проходят порог; fps вынесен в `npm run perf` (см. комментарии)

## Comments

- Модель: `public/models/character-mobile.glb` — `gltf-transform simplify --ratio 0.15 --error 0.002` (1 000 000 → 150 000 треугольников) плюс Draco, 710 КБ. Силуэт, складки капюшона и ботинки читаются — сверено по обновлённому золотому кадру.
- Отступление от чеклиста: запечённой normal map нет. В исходной модели нет UV (только POSITION и NORMAL), запекать не на что; вместо этого оставлены вершинные нормали после децимации. Если понадобится, это отдельная задача на доработку модели.
- Отступление: `antialias: true` оставлен на обоих пресетах. Референс идёт без MSAA, но у нас мобильный рендерит в DPR 1.5 без SMAA-прохода, и отключение MSAA даёт заметную лесенку на контуре статуи. Замер показал запас по кадрам (81 fps в переходе), поэтому MSAA не мешает.
- Пресеты рендера вынесены в `RENDER_PRESET` (`src/scene.js`): mobile — DPR 1–1.5, GTAO не добавляется в композер и не включается при возврате в тёмную сцену, глитч-пасс отсутствует, тени 128; desktop — DPR до 1.5, GTAO в тёмной сцене, тени 2048. `createScene` теперь принимает `preset` и по нему выбирает файл модели; локальная переменная `preset` внутри сцены убрана (конфликтовала с параметром), `attachScroll` больше не принимает пресет.
- E2E `mobile-preset.mobile.spec.js`: запрошена облегчённая модель и не запрошена десктопная, DPR в диапазоне, GTAO выключен, глитча нет в композере, тени 128, треугольников меньше 220k. fps в E2E не проверяется — замер в `npm run perf` (мобильный переход 81 fps при цели 40). Золотой кадр мобильной белой сцены и фолбэк-webp перегенерированы.
