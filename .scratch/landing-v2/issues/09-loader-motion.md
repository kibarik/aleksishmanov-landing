# 09: Анимация лоадера

**What to build:** знакомый с первой секунды видит живую отрисовку золотой спирали, проценты не застревают на 100%, а в финале иконка наклоняется и уходит в глубину, открывая сцену — как у референса.

**Blocked by:** None (can start immediately)

**Status:** done

- [x] Прогресс идёт с первой секунды, не дожидаясь загрузки чанка сцены
- [x] 100% показывается только когда сцена готова; зависания на 100% нет
- [x] Отрисовка динамичная: сетка прорисовывается со сдвигом, спираль идёт с ускорением
- [x] В финале иконка наклоняется в 3D и уходит в глубину, подписи гаснут
- [x] Модель скачивается ровно одним запросом
- [x] E2E: проценты растут до готовности сцены, 100% только при готовой сцене, наклон применён, запрос модели один

## Comments

- Причина зависания: прогресс вёл модуль сцены, который приезжает вместе с чанком three (около секунды и дольше), а до этого полоса стояла. Плюс `link rel=preload` с `crossorigin` не переиспользовался загрузчиком — модель качалась дважды, и на медленной сети проценты замирали на 100 в ожидании второй загрузки.
- Решение: модель скачивает инлайн-скрипт из `index.html` потоковым `fetch` (один запрос, честный прогресс в `window.__modelProgress`), он же ведёт полосу и проценты. Сцена только выставляет `window.__sceneReady` и слушает событие `loader:done`. Без content-length прогресс считается от времени: берётся максимум из реальной загрузки и `elapsed`.
- Динамика: линии сетки прорисовываются с задержкой друг за другом (`--g`), спираль рисуется с ускорением к концу (`easeOut`), у линии появилось свечение.
- Финал: класс `loader--out` наклоняет иконку (`rotateX(16deg) rotateY(-24deg) translateZ(-60px) scale(.9)`) и гасит подписи; через 620 мс лоадер уходит и стартует prelude.
