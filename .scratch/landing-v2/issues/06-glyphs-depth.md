# 06: Глифы кода в глубину

**What to build:** вокруг пьедестала глифы расставлены в пространстве: одни ближе к камере и крупнее, другие дальше и мельче, у каждого свой поворот — кадр читается как 3D-сцена, а не как плоская линейка объектов.

**Blocked by:** None (can start immediately)

**Status:** done

- [x] Глифы разнесены по оси Z и по высоте, у каждого свой масштаб и поворот; ближние заметно крупнее дальних
- [x] Тени на полу соответствуют расположению, ближние глифы не перекрывают пьедестал и имя
- [x] Композиция проверена на 1440×900 и 390×844: ничего не вылезает за кадр
- [x] Мобильный пресет сохраняет расстановку, но компактнее
- [x] E2E: золотые кадры белой сцены перегенерированы и стабильны

## Comments

- Реализовано: глифы разнесены по оси Z от −2.6 до +2.1 и по высоте; ближние крупнее и срезаются краем кадра, дальние мельче и стоят за именем. Мобильная раскладка сжимает по X (0.42) и по Z (0.7), сохраняя порядок глубины.
- Каждый глиф получил имя `glyph-near` / `glyph-far` — по нему тест параллакса отличает передний план от дальнего.
- Золотые кадры перегенерированы.
