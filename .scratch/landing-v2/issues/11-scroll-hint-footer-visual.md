# 11: Подсказка «scroll down» и композиция футера

**What to build:** знакомому в явном виде понятно, что нужно крутить: в правом нижнем углу мышь с колесом и подпись «[ scroll down ]», как у референса. Футер собран вокруг 3D-объекта, а не разнесён по краям с пустой полосой посередине.

**Blocked by:** None (can start immediately)

**Status:** done

- [x] Подсказка крупнее и контрастнее, подпись читается
- [x] Цвет следует за сценой: светлая на тёмной, тёмная на белой
- [x] Подсказка остаётся видимой на белой сцене, прячется только на время перехода и после ухода сцены
- [x] Читается поверх глифов белой сцены
- [x] Футер: объект держит центр кадра, колонки и призыв обнимают его, копирайт внизу слева
- [x] E2E: подсказка в правом нижнем углу, видна на обеих сценах, перекрашивается, прячется после ухода сцены

## Comments

- Подсказка: кегль 11 → 14px гарнитурой Onest, мышь 18×28 → 26×40, цвет `rgba(255,255,255,.85)` на тёмной и `#111` на белой (класс `is-light`). Под текстом и мышью мягкое свечение в цвет фона — на белой сцене подсказка попадает на ближний глиф `}`, и без свечения тёмное по тёмному не читалось.
- Логика показа: раньше подсказка пропадала сразу с началом перехода (`t12 > 0.2`) и на белой сцене её не было вовсе. Теперь прячется только на время перехода (`t12 > 0.2 && t23 < 0.75`, на мобильном аналогично), а на белой сцене возвращается — дальше посетителю тоже надо крутить. После ухода сцены скрыта, как и была.
- Футер: раньше `margin-top: auto` у копирайта съедал всё свободное место и разносил контент по краям — отсюда пустая полоса посередине. Теперь сетка с `align-content: center`, объект абсолютным слоем держит центр (`top: 50%`, срезается нижним краем), копирайт абсолютным позиционированием внизу слева. Глиф сжат с `{ }` до `{}` — две половины читаются одной массой, как рука у референса; центральная колонка сетки расширена, чтобы призыв не налезал на объект. У кнопки появилось мягкое свечение.
