# 10: Прод-проверки и устойчивость к смене сборки

**What to build:** поломку прода видно тестами, а сама страница переживает исчезновение чанка сцены: перезагружается за свежим HTML, а если не помогло — показывает статичный кадр вместо пустого первого экрана.

**Blocked by:** None (can start immediately)

**Status:** done

- [x] HTTP-проверка прода: все ссылки из HTML, чанки из бандла и шрифты из css отдаются с кодом 200, непустые и с верным content-type
- [x] Браузерная проверка прода падает на 4xx/5xx, подменённом типе файла и ошибках консоли; канвас отдаёт непустой кадр
- [x] При неудачном импорте чанка сцены страница один раз перезагружается, затем показывает фолбэк
- [x] E2E воспроизводит поломку: чанк отдаётся как HTML с кодом 200
- [x] README описывает команду и причину

## Comments

- Диагностика жалобы: прод отдавал все файлы корректно (проверено по HTTP), и скачанная прод-сборка локально стартовала со сценой. Значит ломалось не содержимое, а момент: на этом хостинге **несуществующий путь возвращает HTML с кодом 200**, поэтому при смене сборки старый чанк `boot3d` не даёт 404, а приходит как HTML — динамический импорт падает, секции уже отрисованы, а сцена не стартует. Ровно то, что на скриншоте.
- Починка в коде: `import('./boot3d.js').catch(...)` — один раз `location.reload()` (флаг в sessionStorage, чтобы не зациклиться), затем `data-webgl="off"` и обычный фолбэк.
- Тесты: `prod-assets.desktop.spec.js` (по HTTP, работает даже там, где браузер до домена не достаёт), усиленный `prod-smoke.desktop.spec.js`, `scene-chunk-failure.desktop.spec.js`.
