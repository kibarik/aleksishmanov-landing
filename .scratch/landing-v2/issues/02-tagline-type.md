# 02: Теглайн: текст, шрифт и размещение

**What to build:** знакомый читает над именем «Компаниям. Специалистам. Основателям.» — крупнее нынешнего, отдельной гарнитурой и выше по кадру, как строка «Design. Development. Marketing.» у референса.

**Blocked by:** None (can start immediately)

**Status:** done

- [x] Текст теглайна в модуле контента заменён
- [x] Гарнитура теглайна отличается от текста секций и поддерживает кириллицу; вес и кегль подобраны по референсу (около 24px на 1440)
- [x] Положение по вертикали как у референса (около 15% высоты кадра), по центру
- [x] На мобильном помещается в одну-две строки без переполнения
- [x] E2E: текст совпадает с контентом, элемент видим на белой сцене

## Comments

- Реализовано: теглайн стал массивом слов в контенте (`['Компаниям.', 'Специалистам.', 'Основателям.']`), рендерится модулем `src/flipText.js` — слова приезжают переворотом вокруг горизонтальной оси по очереди и повторяют переворот при наведении (пожелание из ответа: флип-текст своим компонентом вместо React-библиотеки).
- Гарнитура: Onest 600 (кириллица есть, геометрия ближе к референсу, чем Montserrat), кегль clamp(16px, 1.7vw, 24px), позиция 14svh — как строка «Design. Development. Marketing.» у референса. На мобильном 17px и 9svh.
- Точки, а не запятые: ритм повторяет референс.
