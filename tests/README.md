# Сравнительные тесты с bersus.io

Референс: `public/ref/bersus-1440.png` (скриншот bersus.io, 1440×900, после лоадера).

Запуск (окно 1440×900, после загрузки модели):

```js
await window.__compare()
```

Возвращает `{ ref, ours, diff, score }`. Метрики описаны в `src/compare.js`.
`score` — взвешенная сумма отклонений, меньше = ближе к референсу.

История прогонов — в `tests/log.md`.
